# DIM004 24W 精衛：功能擴充與實機驗證

這是使用者 fork 的審查版本，尚未提交官方 PR。自動測試與套件相容性載入不代表實機已驗證。

## 本次功能

DIM004 獨立匹配 `modelID: DIM004`、`manufacturerName: Xiaoyan`，保留 DIM003 定義不變。提供：

- 開關、亮度 0–254、色溫 142–625 mired（沿用 DIM003，實際物理範圍仍待讀取）。
- 額定最大電流：**100–1000 mA，步距 10 mA**。轉換器拒絕超出範圍及不符步距的寫入。
- 起光深度校準：0–5000。
- 色溫上下限：各 1000–10000 K，要求最低值小於最高值；依倒數關係換成 mired 寫入。
- 冷暖白輸出 IO 反轉。
- 起光曲線：fast_start（快啟）、uniform（勻速）、slow_start（緩啟）。
- 既有標準狀態回報；訊號品質由 Zigbee2MQTT 提供。

不開啟 RGB、effect、color_temp_startup、power_on_behavior。載入與 configure 僅沿用標準 reporting，**不自動設定電流、校準、色溫限制或輸出反轉**。上述專用設定只有使用者明確操作時才寫入。

## 電流依據與限制

官方家庭中心版本紀錄 v3.2.4（2023-09-13）明列「支持24w精卫驱动 DIM004」：
https://tw.terncy.com/zh-cn/blog/posts/home_center_release_history/

本次唯讀檢查官方 Terncy App 的既有本機反編譯資料：
- `xlive/widget/device_detail_popup.dart`，SetMaxCurrentPage 建立流程：約第 55200–55490 行，DIM004 分支上限 1000，DIM003 分支上限 4950，共用最低值 100 與步距 10。
- `page/set_max_current_page.dart`：共用設定頁，未見 DIM004 專屬替代編碼；經 MqttProxy.writeAttribute 傳給家庭中心。這不是對直接 Zigbee 封包的實機驗證。
- App 警告要求設定值符合燈具額定電流。

**這是 App 提供的設定範圍，不是已量測的驅動器輸出，也不表示所有燈板都可用 1000 mA。** 操作前須核對 DIM004 銘牌、輸出電壓與燈板額定電流。只知道 24W 無法算出安全電流；不得把 DIM003 的 4950mA 乘以 24/100 得到 1188mA。本版本不寫入該推算值。

起光深度、色溫及亮度不是功率，不能乘以 24/100。它們沿用 DIM003 協議值域，不宣稱這些值域已在 DIM004 全範圍實測。

App 的起光曲線入口列出 DIM002/003/004，要求韌體 >= 0xd0（208）；DIM003 另有 >=0x117 的門檻。尚未確認目標 DIM004 實機韌體是否滿足條件。

## 協議與確認範圍

專用 cluster、command、attribute 編碼取自 fork 已有 DIM003 實作，維持相同 manufacturer code 0x1228：
- 電流：0xfccc / powerCalibration（0x08）。
- 校準與色溫：0xfccd / adjustStartLevel（0x00）、setColorTempRange（0x03）。
- IO 與曲線：0xfccd / xyRevertColorTempGpio（0x0005）、xyLightUpCurve（0x0007）。

App 證據支持 DIM004 的電流設定、共用校準頁面及起光曲線入口；尚未逐項證實色溫限制與 IO 反轉在 DIM004 的行為。所有直接 Zigbee 指令的裝置回應仍需實測。設定回傳 state 可能是樂觀狀態，不可單憑畫面數字判定實際生效。

## 部署與實機清單

部署前備份既有外部 converter，替換同名 `terncy-dim004.mjs`，不要另外安裝整個 fork，也不要保留兩份同型號 converter。既有部署不等於本版本已部署。

- [ ] 讀取實機 modelID、manufacturerName、韌體、endpoint 與 clusters。
- [ ] 核對銘牌輸出電壓／電流及燈板額定電流。
- [ ] 讀取 colorTempPhysicalMin／Max（若支援）。
- [ ] 核對 converter 載入日誌與 exposes。
- [ ] 在已知安全設定下逐項實測；不掃描未確認極值。
- [ ] 分清命令成功、樂觀狀態與真實裝置回報。
- [ ] 確認其他設備與 converter 不受影響。
- [ ] 使用者確認後才提交官方 PR。

回復方式：還原備份的外部 converter，依 Zigbee2MQTT 版本重新載入。回復程式不會自動回復先前人工寫進裝置的電流或校準值。
