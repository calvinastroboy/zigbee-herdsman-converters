# DIM004 24W 精衛：審核與實機確認

這是以 DIM003 為參考的 **DIM004 草稿**，尚未提交官方 PR，也尚未以實機驗證。
自動測試通過只表示程式定義與預期一致，不代表 DIM004 硬體已支援。

## 已知與待確認

- Terncy 官方家庭中心 v3.2.4（2023-09-13）明列「支持24w精卫驱动 DIM004」。
- DIM003 的官方支援來自 PR #12311，已合併。
- 尚無 DIM004 的 interview／裝置資料、實機指令紀錄、額定輸出電流或私有協議規格。
- 草稿預期 `modelID: DIM004`、`manufacturerName: Xiaoyan`，**兩者都仍須用裝置讀值確認**。
- 色溫暫沿用 DIM003 的 `142–625 mired`（約 1600–7042 K），**不是 DIM004 實測規格**。
- 開關、亮度、色溫與標準狀態回報也須實測，不能僅以同系列型號認定相容。

- https://tw.terncy.com/zh-cn/blog/posts/home_center_release_history/

## 本次修改

1. `src/devices/terncy.ts`：新增獨立 DIM004 定義，不把它偽裝成 DIM003，也不改動 DIM003。
2. `test/terncy.test.ts`：檢查型號與廠商匹配、標準 exposes、狀態回報、configure/reporting，以及 DIM003 原有功能不變。
3. `review/terncy-dim004.mjs`：同一草稿的外部 converter，可在確認裝置資訊後用於自願的實機測試。

基礎控制使用 DIM003 相同的 `modernExtend.light` 配置：開關、亮度、色溫與標準 reporting。
不開啟 RGB、effect、color_temp_startup、power_on_behavior。

**沒有照搬下列 DIM003 私有功能：**

- 額定最大電流：DIM003 程式允許 120–4950 mA，但沒有 DIM004 的安全電流範圍。不能用 24W 猜電流，也不能按 24/36 比例換算。
- 起光深度校準、色溫範圍寫入、冷暖輸出反接、起光曲線：私有命令／屬性在 DIM004 上是否相同尚未證實。
- 草稿不會自動發送電流設定或上述私有校準指令。

若要加入這些進階功能，需要 DIM004 的廠商協議或可核對的實機讀寫證據。

## 實機驗證清單（先確認，再提交官方）

- [ ] 拍攝 DIM004 銘牌，確認輸入／輸出電壓、輸出電流、24W 標示與負載規格。
- [ ] 在 Zigbee2MQTT 裝置資訊取得 `modelID`、`manufacturerName`、firmware/softwareBuildID。
- [ ] 記錄所有 endpoints 和 input/output clusters；確認開關、亮度、色溫控制所在 endpoint。
- [ ] 讀取 `lightingColorCtrl` 的 `colorTempPhysicalMin`、`colorTempPhysicalMax`（若裝置提供）；核對實際可用色溫範圍，再修正草稿範圍。
- [ ] 使用符合銘牌的負載，在原本已知正常的亮度／色溫範圍測試開、關、亮度調整、色溫調整。不要為驗證草稿任意掃描未確認極值。
- [ ] 確認 Zigbee2MQTT 收到實際狀態回報，不只看發指令後的樂觀狀態。
- [ ] 確認重新啟動 Zigbee2MQTT 後仍可控制，configure/reporting 沒有不支援屬性或超時錯誤。
- [ ] 補齊測試結果、實機型號及產品圖片，再決定提交官方 PR。

尚未由這次工作連接／操作你的實體 Zigbee 網路，也未修改現有 Zigbee2MQTT 設定。

## 外部 converter 試用

先完成型號／廠商／endpoint／色溫範圍確認，必要時修正草稿。備份既有設定後，依所用 Zigbee2MQTT 版本的外部 converter 流程載入 `review/terncy-dim004.mjs`。
這不需要把整個 fork 安裝進正式環境。測試結束若不適用，可移除此外部 converter 並重新啟動。

官方操作說明：https://www.zigbee2mqtt.io/advanced/more/external_converters.html

## 開發驗證

環境：Node.js 24；套件管理器依專案 `packageManager` 使用 pnpm 12.3.4。

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run check
pnpm test
pnpm bench
```

正式測試結果在交付摘要中列出。來源測試為 synthetic fixtures，無實機 I/O。
`review/` 是使用者審核材料；未來向上游提交時只帶已完成實機確認的裝置定義與相關測試，並依上游要求另準備產品圖片。
